Force Menu

A small keyboard-driven helper that writes FORCE 1 / FORCE 2 notes in the standard format and, on request, enters them in the ERP and the intranet using the same clicks and keystrokes a person would. It runs only on the user's PC and never sends, receives or stores bill information.

In one sentence: it replaces typing and copy-pasting the same force notes by hand, while the clerk still reviews and saves every note personally.

The problem it solves

Repetitive typing

Every trouble bill needs a force note in the ERP and an informative note in the intranet, often with a "Hold at term ### due to..." text. Typing them by hand is slow and easy to get wrong.

Inconsistent wording

Free-typed notes vary from person to person. The menu always produces the same wording for the same issue.

Many small steps

Copying the PRO, searching it in the intranet (and in the old intranet for hazmat), opening the note screens... the same clicks dozens of times per shift.

How it works

1. Build the note (keyboard only)

Press Del to open the menu. Choose by elimination: once FORCE 1 is chosen, FORCE 2 options disappear; once an issue is chosen, only its options remain. Several issues can be combined with the numeric keypad.

F1 or F2→ Issue→ Fields→ Terminal (if hold)

2. Enter it (one click, optional)

A small button bar sits in the corner of the screen. It repeats the exact steps the clerk would do with mouse and keyboard, then stops so the clerk can review and save.

Business rules it follows

Hold rules

  • FORCE 2 (hazmat) always carries a hold and a terminal.
  • FORCE 1 carries a hold only when there is a consignee issue.
  • Prohibited freight: shows a red reminder to use the current terminal.

Safety rules

  • Never saves in the ERP or intranet. The clerk always reviews and saves.
  • Each note can be pasted once, so the previous bill's note is never pasted by mistake.
  • If a window is not found or a step fails, it stops and says where. It never keeps typing blindly.

Security and privacy

What it does

  • Runs with Windows PowerShell, already included in Windows. Nothing is installed.
  • Works only on the local PC, with the windows already open on screen.
  • Uses the clipboard and simulated clicks/keys, the same as a person.
  • Reads the keyboard only to detect its own keys (Del, Insert). It is not a keylogger and records nothing typed.

What it does NOT do

  • No internet or network connection of any kind.
  • No access to databases, servers or other systems.
  • Does not store PROs, terminals, customer names or note text on disk.
  • Does not modify the ERP, the intranet or any company file.
  • No administrator rights needed.

The only files it writes are optional: screen coordinates for the clicks (numbers like "100, 115") and a troubleshooting log with step names only (for example "ERP found", "click on search box"). Both can be turned off and never contain bill data.
